## 关于嘉潮供应链

**嘉潮供应链**围绕 POD（按需印制）电商，研发面向图案素材、绘图服务与多站点业务的软件。

我们的项目从图库与素材管理出发，覆盖客户绘图需求、订单协作和 AI 辅助图像处理，也在探索素材编辑与设计工具之间更顺畅的衔接。

## 项目方向

| 方向 | 我们在做什么 |
| :--- | :--- |
| **图库与站点** | 图案素材的整理、检索与展示，以及面向浏览、选购和下载的多站点应用。 |
| **绘图业务协作** | 围绕绘图需求、订单、参考图、附件和交付资料，建设业务管理与协作工具。 |
| **AI 图像工具** | 研发与集成图片编辑、图案提取、提示词生成和图片检索等处理能力。 |
| **POD 创作工作台** | 探索素材整理、轻量编辑及设计软件协作；相关工作仍处于原型验证阶段。 |

## 项目如何配合

图库与业务管理提供素材、需求和订单基础，站点提供内容呈现与用户入口。AI 工具侧重图像处理，创作工作台则用于验证素材编辑与设计协作的体验。

> 以图案为起点，围绕素材、创作与业务流程持续研发。
